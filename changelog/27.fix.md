Fixed pre-release detection in `bump-version`, which matched a bare `a`, `b`, `rc` or `dev` anywhere in the version string. A version carrying a local segment such as `1.2.3+abc` was misread as a pre-release, silently skipping both the follow-up dev bump and the draft GitHub release. Detection is now version-scheme aware: PEP 440 for `project-type: uv`, semver for `project-type: yarn`.
